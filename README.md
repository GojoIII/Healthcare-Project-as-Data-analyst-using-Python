# Heart Disease Analysis and Machine Learning

## Project Overview

This project explores a heart disease dataset using Python to identify patterns, understand relationships between health-related variables, and evaluate machine learning classification models.

The project covers data exploration, data quality checks, statistical analysis, visualization, feature scaling, model evaluation, and interpretation of classification results.

**Project Type:** Healthcare Analytics and Machine Learning  
**Domain:** Healthcare  
**Language:** Python

## Objectives

- Explore and understand the heart disease dataset.
- Inspect data types, missing values, and descriptive statistics.
- Analyze distributions and relationships between health-related features.
- Visualize correlations and patterns using statistical charts.
- Prepare features and split data into training and testing sets.
- Train and evaluate classification models.
- Communicate findings through visualizations and model evaluation metrics.

## Tools and Technologies

- **Python** — data analysis and modeling
- **Pandas and NumPy** — data manipulation and numerical operations
- **Matplotlib and Seaborn** — statistical visualization
- **Plotly Express** — interactive visualizations
- **Scikit-learn** — preprocessing, model training, and evaluation
- **Jupyter Notebook** — interactive analysis

## Dataset Description

The dataset contains 303 records and 14 columns, including 13 input features and one target column named `output`.

Features include age, sex, chest pain type, resting blood pressure, cholesterol, fasting blood sugar, resting ECG, maximum heart rate, exercise-induced angina, ST depression (`oldpeak`), slope, number of major vessels (`caa`), and thalassemia-related category (`thall`).

The `output` column represents the dataset's target classification. Confirm its exact label definitions from the original dataset documentation before interpreting it clinically.

## Project Workflow

1. Import libraries and load the dataset.
2. Inspect the dataset's structure and statistical summaries.
3. Check missing values and data quality.
4. Perform exploratory data analysis (EDA).
5. Visualize feature distributions and relationships.
6. Analyze correlations between variables.
7. Prepare input features and the target variable.
8. Split the data into training and testing sets.
9. Apply feature scaling where appropriate.
10. Train classification models.
11. Evaluate results using accuracy, a confusion matrix, precision, recall, and F1-score.
12. Interpret findings and document limitations.
